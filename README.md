# quant-trading-python-notes

一个使用 Python 代码与 Markdown 笔记系统学习量化交易的仓库，聚焦从基础概念到策略实践的持续积累。

A repository for learning quantitative trading through Python code and Markdown notes, focused on building knowledge from core concepts to strategy practice.

> 仅用于学习与研究，不构成任何投资建议。  
> For learning and research purposes only. This repository does not constitute investment advice.

## 项目简介 / About

这个仓库用于系统记录量化交易学习过程，结合 Python 实验代码与 Markdown 学习笔记，逐步整理知识框架、策略思路和实践复盘。内容会尽量保持从基础到进阶的连续性，方便长期沉淀与回顾。

This repository is designed to systematically document the journey of learning quantitative trading. It combines Python experiments with Markdown notes to organize concepts, strategy ideas, and review summaries over time. The goal is to keep the content structured, practical, and easy to revisit.

## 学习目标 / Learning Goals

- 学习量化交易的基础概念、常见流程和核心方法。
- 使用 Python 完成数据获取、清洗、分析与简单回测。
- 通过 Markdown 沉淀知识点、策略思路、实验记录和复盘总结。

- Learn the core concepts, common workflows, and key methods of quantitative trading.
- Use Python for data collection, cleaning, analysis, and simple backtesting.
- Use Markdown to capture knowledge points, strategy ideas, experiment logs, and review notes.

## 学习路线 / Roadmap

### 阶段 1：Python 基础与数据分析工具 / Phase 1: Python Fundamentals and Data Analysis Tools

- 巩固 Python 基础语法与常用编程习惯。
- 学习 NumPy、pandas、matplotlib 等常用数据分析工具。
- 建立面向量化研究的基础代码能力。

### 阶段 2：量化交易基础概念与常见指标 / Phase 2: Quant Basics and Common Indicators

- 理解量化交易的基本框架、常见策略类型与研究流程。
- 学习收益率、波动率、回撤等基础指标。
- 熟悉均线、MACD、RSI 等常见技术指标的含义与使用场景。

### 阶段 3：策略开发与简单回测 / Phase 3: Strategy Development and Simple Backtesting

- 基于历史数据尝试构建简单策略。
- 学习如何验证策略表现并分析结果。
- 记录策略假设、实验过程与初步结论。

### 阶段 4：项目化整理与持续复盘 / Phase 4: Structured Organization and Continuous Review

- 将零散实验整理成可复用的学习模块。
- 持续补充笔记、案例和策略复盘。
- 优化目录结构，形成长期维护的个人学习仓库。

The following is the proposed repository structure for organizing future content in a clear and scalable way:

- 数据获取与清洗 / Data sourcing, preprocessing, and cleaning
- 策略设计 / Strategy ideas, logic design, and hypothesis building

## 使用方式 / How to Use

- 阅读 `notes/` 中的 Markdown 笔记，按主题理解基础知识与学习过程。
- 运行 `code/` 中的 Python 示例，结合数据分析与策略实验进行实践。
- 按照 Roadmap 逐步补全内容，把仓库作为长期学习与复盘的记录空间。

- Read the Markdown notes in `notes/` to follow key concepts and learning progress.
- Run the Python examples in `code/` to practice data analysis and strategy experiments.
- Follow the roadmap step by step and use this repository as a long-term learning journal.
